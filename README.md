# BD Children's Haven — কাস্টম স্টোর সেটআপ গাইড

এই ফোল্ডারে একটা সম্পূর্ণ Node.js ওয়েবসাইট আছে:
- **পাবলিক স্টোর** (`/`) — প্রোডাক্ট দেখা, কার্ট, চেকআউট
- **অ্যাডমিন প্যানেল** (`/admin/login.html`) — প্রোডাক্ট যোগ/এডিট/ডিলিট, অর্ডার দেখা
- **পেমেন্ট** — SSLCommerz (bKash, Nagad, Rocket, কার্ড — সব একসাথে কভার করে)

---

## ধাপ ১ — নিজের কম্পিউটারে টেস্ট করা

```bash
cd bd-childrens-haven
npm install
cp .env.example .env
npm start
```

এরপর ব্রাউজারে যান:
- স্টোর: `http://localhost:3000`
- অ্যাডমিন: `http://localhost:3000/admin/login.html`
  (ডিফল্ট: username `admin`, password `.env` ফাইলে যা দিয়েছেন)

SSLCommerz credentials না দেওয়া পর্যন্ত checkout স্বয়ংক্রিয়ভাবে **Cash on Delivery** হিসেবে কাজ করবে, যাতে বাকি সব টেস্ট করা যায়।

---

## ধাপ ২ — SSLCommerz অ্যাকাউন্ট (bKash/Nagad/Rocket-এর জন্য)

1. **Sandbox (টেস্ট) অ্যাকাউন্ট** ফ্রি ও সাথে সাথে পাবেন:
   `https://developer.sslcommerz.com/registration/`
2. Sandbox থেকে পাওয়া `Store ID` আর `Store Password` বসান আপনার `.env` ফাইলে:
   ```
   SSLCOMMERZ_STORE_ID=...
   SSLCOMMERZ_STORE_PASSWORD=...
   SSLCOMMERZ_IS_LIVE=false
   ```
3. এখন sandbox পেমেন্ট পেজ দিয়ে টেস্ট bKash/কার্ড ট্রানজেকশন করে পুরো ফ্লো চেক করুন।
4. **আসল টাকা নিতে (Live)**:
   - আপনার ব্যবসার ট্রেড লাইসেন্স, ব্যাংক অ্যাকাউন্ট ইত্যাদি দিয়ে SSLCommerz-এ মার্চেন্ট ভেরিফিকেশন করাতে হবে (কয়েকদিন লাগে)।
   - অনুমোদন হলে তারা Live Store ID/Password দেবে — `.env`-এ বসিয়ে `SSLCOMMERZ_IS_LIVE=true` করে দিন।
   - বিকল্প: **ShurjoPay** বা **aamarPay** — একই ধরনের aggregator, চাইলে পরে সুইচ করা যায়।

## ধাপ ৩ — ইন্টারনেটে হোস্ট করা (ডোমেইনে লাইভ করা)

সহজ, কম খরচের রাউট:

1. **হোস্টিং**: [Render.com](https://render.com) বা [Railway.app](https://railway.app) — এদের ফ্রি/সস্তা প্ল্যানে Node.js অ্যাপ সহজে ডিপ্লয় করা যায়। GitHub-এ কোড push করে সেখান থেকে কানেক্ট করবেন।
2. **ডোমেইন**: `.com.bd` বা `.com` — যেকোনো বাংলাদেশি বা ইন্টারন্যাশনাল রেজিস্ট্রার (Namecheap, Exonhost ইত্যাদি) থেকে কিনে হোস্টিং প্রোভাইডারে পয়েন্ট করবেন।
3. ডিপ্লয়ের সময় Environment Variables ট্যাবে `.env`-এর সব ভ্যালু বসিয়ে দিন — বিশেষভাবে:
   - `BASE_URL` = আপনার আসল ডোমেইন (যেমন `https://bdchildrenshaven.com`) — এটা না বসালে পেমেন্ট রিডাইরেক্ট কাজ করবে না।
   - `ADMIN_PASSWORD` ও `SESSION_SECRET` — শক্তিশালী, র‍্যান্ডম ভ্যালু দিন।

⚠️ ডেটাবেজ ফাইল (`data/store.db`) সাধারণ ফ্রি হোস্টিং-এ রিস্টার্টে মুছে যেতে পারে (ephemeral storage)। প্রোডাকশনে গেলে Render-এর **Persistent Disk** অ্যাড-অন যোগ করুন, নাহলে ডেটাবেজ পরে PostgreSQL-এ পরিবর্তন করার পরামর্শ দেব।

## ধাপ ৪ — প্রোডাক্ট কীভাবে আপডেট করবেন

`/admin/login.html`-এ লগইন করে:
- **নতুন প্রোডাক্ট যোগ**: উপরের ফর্মে নাম, ক্যাটাগরি, দাম, স্টক, ইমোজি/আইকন, ট্যাগ দিয়ে "Add" চাপুন।
- **এডিট**: টেবিলের যেকোনো সারিতে "Edit" চাপুন, ফিল্ড পাল্টান, "Save" চাপুন।
- **ডিলিট**: "Delete" চাপুন।
- **স্টক আউট করতে না চাইলে**: Active = "No" করে দিলে প্রোডাক্টটি স্টোরফ্রন্টে দেখাবে না কিন্তু ডিলিট হবে না।

প্রোডাক্ট ছবি এখন ইমোজি/আইকন দিয়ে দেখানো হচ্ছে। আসল প্রোডাক্ট ছবি বসাতে চাইলে জানাবেন — আপলোড সিস্টেম যোগ করে দেব।

---

## ধাপ ৫ — অর্ডার দেখা

অ্যাডমিন প্যানেলের "Orders" ট্যাবে প্রতিটা অর্ডার — কাস্টমারের নাম, ফোন, আইটেম, টাকার পরিমাণ ও পেমেন্ট স্ট্যাটাস (PENDING/PAID/FAILED/CANCELLED) দেখা যাবে।
